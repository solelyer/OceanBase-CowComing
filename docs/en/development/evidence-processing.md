# Evidence processing and lifecycle

`powercontext.sources.pdf_pages` parses original PDF bytes with pypdf. `parse_pdf_document(PDFDocumentInput(document_id=..., content=...))` returns every physical page, including blank pages, and hashes the complete original file. The `PDF_PAGE_SOURCE_DEFINITION` captures each page under an identity derived from document ID, full-file SHA-256 and one-based physical page number. Its text-evidence projection contains the document ID, original page text and exact location metadata. Empty-password permission markers are supported; unreadable or incomplete PDFs fail atomically with `ValueError`. OCR is outside this adapter's scope. A new PDF revision creates new identities and leaves old citations readable.

`search_pdf_pages(scoped_memory, question, limit=10)` searches native Memory with the original content terms, short subqueries and general financial vocabulary. It normalizes fiscal-year notation and abbreviations such as D&A, and ranks the pooled page bodies using BM25, relevant statement headings and document issuer/year matches. Short subqueries let complementary evidence pages qualify independently instead of requiring every page to cover a long question. All returned citations come from actual scoped search hits and retain their exact entry versions. This uses multiple local full-text searches per question; it requires no model, online service, annotations or extra dependency.

Set `PrepareContextRequest(evidence_selection=True, ...)` to choose original Memory fragments by query rather than the ordinary whole-entry assembly policy. The default remains false. The selector scores sentence intervals with local lexical statistics, can merge adjacent intervals from the same entry, and measures the entire rendered UTF-8 output before admitting a fragment. Each `PreparedContextBuild.fragments` item contains a scoped `MemoryEntryAddress`, Python character offsets and the exact original slice. Origins correspond one-for-one to fragments. The trust policy, envelope, JSON, references and text all count against `max_bytes`; an empty result is legal. Selection uses neither a model nor relevance annotations. It handles Memory candidates; other artifact families are not assembled in this mode.

`RuntimeConfig.memory_source_count_threshold` and `topic_memory_source_count_threshold` accept a positive integer or `None`. Booleans, strings and floating-point values are rejected. Counts inspect persisted Source identities after each family's last successful cursor, independently for every scope. Duplicate capture and receipt trust upgrades keep the same identity. Lineage-only Sources count toward admission but retain their existing exclusion from generation evidence. Count and time conditions independently admit work. Explicit flush bypasses the count threshold. Memory rechecks after each consumed window; Topic Memory completes an already accepted wave using its existing window behavior. Failed accepted work retains the native retry and restart path.

The Python Runtime exposes `runtime.lifecycle.for_scope(scope_id)`. Register captured Source references with a lifecycle revision, exact Memory citations with parents and `all`/`any` policy, and Topic artifact references with parents. Parents must already exist, so registration cannot introduce cycles. Repeated identical registration is idempotent; conflicting bindings fail. Derived nodes immediately inherit current support, including when registered after withdrawal.

Apply a strictly typed `SourceLifecycleEvent(node_id=..., revision=..., sequence=..., available=..., reason=...)` to a registered Source. Revisions must match and sequence numbers increase. Exact successful replay is idempotent. Propagation retires or reactivates native Memory entries while preserving body versions. Topic qualification affects native search, browse and prepared Context while exact historical reads remain available. `resolve(node_id, purpose="generation")` rejects unsupported nodes; `purpose="audit"` returns the original reference. Registrations and committed events are persisted per scope. If propagation is interrupted, retrying the event completes pending work without repeating already applied Memory state changes. Each scope uses one writer and a fixed graph after registration; registered Memory bodies must not be externally rewritten.

The embedded seekdb Memory index retains its existing schemas and write projections. Hybrid retrieval uses one CTE/UNION statement for both full-text and approximate vector candidates, applying scope, artifact, tag and channel limits within the database. Fusion and exact body expansion follow the existing Memory path. Single-channel queries retain their prior implementations, and current-head validation continues to protect references.

Use the published targets in `competition/Makefile` for offline public acceptance. These tests establish their published scenarios. They do not establish the full FinanceBench/SciFact retrieval thresholds, the full incremental transmission benchmark, or performance under the official resource quota.
